# AI 客服信件分類器（AI Email Classifier）

## 1. 專案介紹

本專案使用 Python 與 Ollama 本地大型語言模型 Qwen2.5 3B，開發一套 AI 客服信件分類程式。

使用者提供客服信件後，模型會自動分析信件內容，判斷問題類別與緊急程度，並產生問題摘要及建議回覆，以協助整理客服資訊。

## 2. 專案功能

- **信件分類：** 物流問題、退款問題、產品問題及其他。
- **緊急程度判斷：** 高、中、低。
- **問題摘要：** 自動提取信件主要內容。
- **建議回覆：** 產生繁體中文客服回覆。
- **Structured Output：** 使用 Pydantic 定義 JSON Schema，並驗證 LLM 輸出格式。
- **批次測試：** 自動處理三封測試信件，並儲存分析結果。

## 4. 環境設定與執行方式

本專案使用 Python 3.11，並透過 uv 管理執行環境。

**步驟一：安裝套件**

在專案根目錄執行：

`uv sync`

**步驟二：下載 Ollama 模型**

確認 Ollama 已安裝並啟動，執行：

`ollama pull qwen2.5:3b`

**步驟三：執行單封信件分類**

`uv run main.py`

執行後，模型將分析程式中預設的客服信件，並將結果儲存為 `docs/result.json`。

**步驟四：執行批次測試**

`uv run batch_test.py`

程式將依序分析 `examples/test_cases.json` 中的三封測試信件，並將結果儲存為 `docs/results.json`。

## 6. AI 使用說明

### 使用工具

**ChatGPT：** 協助規劃程式架構、提供 Python 程式範例、設計 Structured Output 與批次測試流程，以及說明 Git 版本控制操作。

**Ollama（Qwen2.5 3B）：** 在本地端執行大型語言模型，完成客服信件分類、緊急程度判斷、摘要與回覆文字生成。

### 個人實作與驗證

- 使用 uv 建立 Python 專案環境。
- 在本地端執行 Ollama 模型並確認能正常回應。
- 執行單封客服信件分類程式，確認能產生 JSON 輸出。
- 執行三封信件的批次分類測試，核對預期類別與實際分類。
- 使用 Git 建立程式版本紀錄。

### AI 使用限制

大型語言模型可能發生分類錯誤、判斷偏差或產生不正確的回覆內容，因此模型結果仍需人工檢查。本專案目前僅進行小規模功能測試，尚未建立完整的客服分類效能評估。
