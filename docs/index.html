01

做了什麼？

透過 Python 呼叫本地 Ollama 的 Qwen2.5 3B 模型，針對客服信件進行語意分析，將結果輸出為具備固定欄位的 JSON。使用 Pydantic 定義 JSON Schema 並驗證回傳格式。

信件分類物流、退款、產品問題、其他
緊急程度高、中、低
自動摘要萃取主要問題
建議回覆生成繁體中文回覆草稿

客服信件 → Python → Ollama / Qwen2.5 → Pydantic 驗證 → JSON 結果

02

怎麼執行？

環境需求：Windows、Python 3.11（由 uv 管理）、uv 與 Ollama。先取得 GitHub 專案並安裝依賴，確保 Ollama 服務正在運作。

  1. 安裝專案依賴：uv sync
  2. 下載模型：ollama pull qwen2.5:3b
  3. 執行單封分類：uv run main.py
  4. 執行三封信件批次測試：uv run batch_test.py

批次測試會將結果儲存至 docs/results.json。詳情參考 README。

AI 使用說明

使用工具：ChatGPT 協助規劃程式架構、提供 Python 與網頁實作範例、說明 Git 操作；Ollama／Qwen2.5 3B 負責實際分析客服信件。

實作與驗證：在 Windows 本地端建立 uv 專案、執行單封與三封信件分類、檢查 JSON 輸出，並將測試結果納入版本紀錄。最終部署狀態以 GitHub Actions 紀錄為準。

限制與責任：AI 可能分類錯誤、誤判緊急程度或提供不適當的回覆；本程式為課程示範，未直接連結真實訂單或客服系統。對外使用前應再增加測試、個資保護與人工審核機制。
